# 國一自學站（冒險島）

給國中一年級學生在家自學用的互動網站，科目是**生物（康軒版）**與**社會（南一版，分地理、歷史、公民）**。
每個單元是地圖上的一座島，依「重點整理 → 互動活動 → 測驗 → 錯題本」的順序學習，進度存在瀏覽器裡。

純靜態網站：只有 HTML、CSS、JavaScript，不需要安裝任何東西、不需要伺服器。
3D 地圖用的 Three.js 已放在 `js/vendor/three.min.js`（r158，UMD 版），所以離線也能開。

## 遊戲化規則

- **闖關順序**：生物、地理、歷史、公民四條路線各自獨立，每條的第一關一開始就開；打倒上一關的 BOSS（測驗答對 80% 以上）才解鎖下一關。鎖住的島是灰色加鎖頭，點了咕博士會提醒。
- **BOSS 戰**：每關的測驗是打怪。BOSS 血量等於題數，答對一題扣一格；玩家有 3 顆愛心（題數 × 0.2 + 1），答錯掉一顆，掉光就挑戰失敗，可以無限次再挑戰。失敗時只有實際作答過的錯題會進錯題本。連續答對會顯示連擊。
- **家長開關**：右上角「進度」裡的「解鎖全部關卡」。學校進度超前、孩子要直接練正在上的章節時打開；關掉就恢復依序解鎖。音效也在同一處開關。
- **三顆星**：每座島三顆星，分別是「讀完重點」「活動全部完成」「測驗答對 80% 以上」。三顆集滿升起**金旗**。
- **經驗值與等級**：由進度推算（重點 20、每個活動 15、每題曾答對 5、測驗曾達 80% 另加 30、錯題重練答對 10）。重測同一份測驗不會重複加分。等級 = √(經驗值 ÷ 60) + 1。
- **徽章**：第一顆星、第一面金旗、全對、錯題清零、連續三天、連續七天、生物島主、社會島主。在右上角「進度」可看徽章櫃。
- **連續天數**：每天有任何學習動作就累積一天，中斷重新計算。
- **咕博士**：地圖上站在你該去的島；單元頁右下角會依情況說話，點牠可收合泡泡。
- 第一次進站會請孩子輸入名字；名字可在「進度」裡修改。
- 無法使用 WebGL 的瀏覽器會自動改顯示島嶼清單，功能不受影響。

## 怎麼打開

**方法一：直接開檔案（電腦）**
把整個資料夾下載到電腦，雙擊 `index.html` 就能用，不需要網路。

**方法二：放上 GitHub Pages（手機、平板也能用）**
1. 把整個資料夾推到 GitHub 的一個 repository。
2. 到 repository 的 Settings → Pages，Source 選 `Deploy from a branch`，Branch 選 `main`、資料夾選 `/ (root)`，存檔。
3. 幾分鐘後網址會是 `https://<你的帳號>.github.io/<repository 名稱>/`，用手機打開就能學。

## 內容校對提醒

所有單元的講解與題目都是依 108 課綱原創撰寫，**不是**課本原文。
上線前請對照手邊的課本把每個單元看過一遍；發現需要修正的地方，直接改 `content/` 底下的對應檔案即可。
每個內容檔的第一行都有提醒註解。

## 怎麼新增單元

1. 複製 `content/_example.js`，放到 `content/bio/` 或 `content/soc/<geo|hist|civ>/`，改檔名與內容。
2. 在 `content/manifest.js` 加一行新檔案的路徑。
3. 執行 `npm run validate`，看到「全部合法」才算完成。

欄位說明與六種互動活動的資料格式見 [docs/content-format.md](docs/content-format.md)。

## 開發與測試

需要 Node.js 22 以上（只用於測試與驗證，網站本身不需要）。

```bash
npm test            # 邏輯單元測試（進度儲存、計分、路由、驗證腳本、獎勵、地圖版面）
npm run validate    # 檢查所有內容檔
node dev/serve.js   # 在 http://localhost:8787 預覽（可省略，直接開 index.html 也行）
```

試驗頁：`dev/activities.html`（六種互動活動）、`dev/mascot.html`（咕博士、通知、彩帶）、`dev/map.html`（3D 地圖）。

```

js/                     共用模組、六種活動元件、畫面
js/game-logic.js        星星、經驗值、徽章、連續天數（純邏輯）
js/map/                 3D 地圖：版面、場景、島嶼、標籤
js/mascot.js            咕博士、對話泡泡、通知卡、彩帶

tools/validate-content.js  內容驗證腳本
tests/                  node:test 單元測試
docs/                   設計文件、實作計畫、內容格式說明
```

## 進度

學習進度存在瀏覽器的 localStorage，換裝置或換瀏覽器不會自動同步。
右上角「進度」可以匯出成 JSON 檔、在另一台裝置匯入，或清除全部進度。

# 闖關遊戲化（第三階段）：設計說明

日期：2026-11-01。建立在冒險島（第二階段）之上。家長要求「做成類似電動闖關遊戲」，並選擇**依序解鎖**。

## 規則
- **路線與關卡**：生物、地理、歷史、公民四條路線各自獨立；每條路線的第 1 關一開始就解鎖。
- **過關**：該關 BOSS 戰（測驗）答對比例 ≥ 80%（沿用「測驗星」）。過關即解鎖同路線下一關。三顆星（重點＋訓練＋BOSS）升金旗仍照舊。
- **BOSS 戰**：怪物 HP ＝ 題數；答對一題扣 1 HP；玩家愛心 ＝ `floor(題數 × 0.2) + 1`（12 題 → 3 顆）；答錯掉一顆，愛心歸零即**挑戰失敗**（此時剩餘題視為未答，分數照實記錄，`rightEverIds` 照樣累積）。連擊 ＝ 連續答對數，結算顯示最高連擊。失敗畫面：剩餘 HP、建議「回去看重點」或「錯題本」、「再挑戰」。過關畫面：分數、用時、最高連擊、獲得的星、「下一關已解鎖」。
- **地圖**：未解鎖的島灰色＋鎖頭標籤，點擊不進入，咕博士提示「先打倒上一關的 BOSS」。島嶼清單同樣顯示鎖頭且不可點。
- **家長開關**：「進度」對話框內「解鎖全部關卡（家長用）」，存在 `player.unlockAll`，開啟後所有島可進；關閉即恢復依序解鎖。
- **直接輸入網址進入鎖住的關**：顯示鎖定畫面與回地圖按鈕，不渲染內容。
- **音效**：WebAudio 合成（答對、答錯、過關、失敗、拿星），預設開、可在進度對話框關閉；偏好存 localStorage 鍵 `jh-learn-sound`。
- **分頁文案**：重點整理 → 「重點」、互動活動 → 「訓練場」、測驗 → 「BOSS 戰」、錯題本不變。

## 實作者的決定
- 解鎖只看「測驗過關」，不要求活動或重點，避免卡住想直接挑戰的孩子；但重點與訓練仍影響星星。
- 失敗不扣任何已得的星星或經驗值（經驗值由狀態推算，答對過的題仍算）。
- 怪物外觀依路線四種（生物：史萊姆、地理：岩石怪、歷史：幽靈船長、公民：機器人），純 SVG。
- 不做時間限制。

## 純邏輯（可測）
- `unlockedMap(units, statesById, unlockAll)` → `{ [id]: boolean }`
- `newFight(total)` → `{ hp, maxHp, hearts, maxHearts, combo, maxCombo, failed }`
- `applyAnswer(fight, correct)` → 新 fight
